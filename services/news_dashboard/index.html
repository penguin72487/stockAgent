05

統計口徑

  • 已保存正文按唯一網址計數；正文版本、股票關聯列與 metadata 不同，不可混加。網址去重不是跨媒體內容級去重。
  • 條件估時只外推目前已知可回補網址，使用目前 owner 的完整經過時間與耐久提交版本。新 sitemap、重抓、來源拒絕和未啟用範圍不包含在完成承諾中。
  • 來源處於冷卻、程序停止或快照過期時不繼續顯示有效 ETA；更新失敗保留最後資料並標示過期。
  • 正文 UTF-8 大小不是壓縮後容量；完整下載流量與總容量尚未知，不用短期平均冒充精確總量。
  • 正文與原始 HTML 僅在私人下載工作區；本頁不提供文章、控制下載、觸發來源 API 或自動訓練注入。
