你看到的數字怎麼來

公開面板只呈現必要的聚合證據。

零額外 API 成本

面板不呼叫 login、ticks 或 kbars；只讀既有 manifest、receipt、systemd 狀態與嚴格解析後的 journal 數字。

三種配額口徑

「歷史流量」會累積 api.usage()；「即時推送」不扣歷史額度；「本機衍生」不再呼叫永豐 API。

公開資料最小化

不輸出 API Key、Secret、身分、帳號、憑證、本機路徑、capture ID 或 systemd invocation ID。

完成與運行分離

批次資料以 manifest 與稽核判定完成；即時資料才以服務狀態及最新落盤時間判定是否健康。
