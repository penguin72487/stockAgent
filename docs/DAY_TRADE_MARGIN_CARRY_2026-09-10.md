## 3. 成本與會計範圍

沿用目前四模型設定的壓力假設，並非券商報價：

| 項目 | 假設 |
| --- | ---: |
| 融資計息本金比例 | 60% |
| 融資年率 | 16% |
| 融券年率 | 20% |
| 融券轉入一次處理費 | 0.1% |
| 計息天數 | 實際日曆天／365，含週末 |

轉融券的原賣出稅額差、後續非當沖部位出場費稅，使用既有 canonical 費率向量。每筆成本入原子 state 的 `carry_cost_ledger`，同日重試、重啟不重複計息／收取轉入費。

```text
帳戶 NAV = 初始本金 + 累積已實現淨損益
           + 未平倉淨清算損益 - 累積跨日成本
```

Web／Discord 共用同一 performance contract，揭露 margin 契約、壓力成本、估值過期及企業行動等待原因。這不是已驗證的券商可用購買力，尚不包含完整 T+2 現金授信與除權息應收應付帳戶；沒有真實下單、登入券商或更動訓練 checkpoint。

真實轉換不是人人自動獲准，必須依券商與交易所程序辦理；本次只採使用者明確授權的模擬假設。[TWSE 當日沖銷交易專區](https://www.twse.com.tw/zh/products/system/day-trading.html)。
