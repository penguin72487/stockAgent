# 當沖來源優先與 FinLab 接續更新

紀錄時間：2026-10-28 08:48，亞洲／台北。此文件的狀態是當時觀測，不是往後每次開盤的保證。

當沖的公開資料檢查、來源更新、盤前準備、即時行情、模擬執行及訊息服務優先於歷史下載與儲存整理。一般大量下載仍維持使用者要求的暫停。當沖來源使用既有的來源鎖、公開資料交易日曆及現有執行者；停用歷史下載不代表當沖所需的增量追新也要停止。

已啟用的 `stockagent-finlab-daytrade-priority.timer` 從目前選定的模型 manifest 與經 SHA 驗證的特徵字典找出 FinLab 依賴，依既有來源檢查時程將到期項目登記為有限優先工作，再透過同一個 FinLab 下載器與帳號鎖執行。`stockagent-finlab-daytrade-projection.timer` 偵測已驗證的本機來源收據與已發布投影的來源版本不同時，等待既有產生器釋放鎖，呼叫原本的 completed-session 產生器與發布流程。這不等同於來源一定有新值、模型已使用新值或交易已成交。

有限優先工作先登記、再取得帳號鎖；若一般歷史下載正在執行，它會在當前資料集完成的安全邊界確認經內容雜湊驗證的當沖工作，交還帳號，不中斷 SDK 呼叫。當沖追新不等待歷史資料全數完成。

有限優先追新可以使用背景下載專用的 64 GiB 驗證預留；一般下載仍維持該預留。控制與帳本所需的 25 GiB 共用保留、WSL 實際所在 Windows 磁碟的容量檢查、來源配額、授權與真實錯誤仍有效。長時間執行的優先批次會在項目之間定期重檢空間；無法判定實際磁碟容量時不能假裝已獲准。CPU 權重由核心爭用時分配，不是速度保證；I/O 權重效果取決於底層排程器。

本次選定的模型有 350 個 FinLab 資料集依賴，檢查時 219 個到達原本排定的來源重查時間，並不表示 219 個都有新資料。追新已取得新版本；投影在追新前就開始建置，因此必須等原產生器發布並再次核對新來源版本，才能證明後續投影已納入。舊版投影或執行中的建置不能冒稱最新。
